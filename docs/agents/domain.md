# Domain documents

Status: current project convention, 2026-10-16.

This collection uses one root [glossary](../../CONTEXT.md), with sections for its areas. Keep it to definitions; command syntax, plans and implementation state belong elsewhere. Preserve existing Learning definitions when changing media terminology.

Record an ADR in [docs/adr](../adr/) only for a consequential trade-off that would surprise a future maintainer without context. Number new ADRs after the highest existing number. State the decision and why in a few sentences. When revisiting it, mark the old decision superseded and link the replacement; retain the historical reasoning.

For capability designs and verification records, start at [the documentation index](../README.md). These conventions work without installing Matt's Skills; available Matt Skills can consume the same pointers.
