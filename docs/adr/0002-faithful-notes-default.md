# Preserve the lecture by default

Status: accepted. Recorded 2026-10-16 after the original condensed-note case.

A request for notes defaults to a faithful lecture script, preserving substantive expression and original progression; condensation requires an explicit request. Attractive layout is achieved through speech cleanup, paragraphs and relevant screenshots rather than silently removing explanations. This choice follows user feedback that the original summarized edition lost important expression. Source and image review remain necessary; character ratios, image counts and structural checks are evidence aids rather than completeness proofs.
