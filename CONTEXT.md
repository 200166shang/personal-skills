# Personal Learning Skills

This glossary defines the learning stages and artifacts shared by the Learning skills.

## Learning Workflows

**Root Question**:
An exploratory entry point for learning an unfamiliar area; it can lead to recursive Questions as understanding develops.
_Avoid_: Interview prompt

**Topic**:
A coherent, readable synthesis of what the learner has explored about a subject. It aims to preserve the full explanation rather than select only interview material.
_Avoid_: Interview answer

**Review**:
A practice session where the learner explains a previously learned module's solution or implementation, and receives feedback on the most important gaps plus a clearer spoken version. It aims for understandable explanation, not exhaustive recall of saved details.
_Avoid_: Detail quiz, comprehensive question bank

**Review Scope**:
One previously studied Topic or project module explicitly selected for a Review session. Related Questions, Research, and implementation material can support it; neighboring modules do not become separate review subjects.

**Interview Q&A**:
A finalized, reusable, module-representative interview prompt—proposed by the assistant or specified by the learner—paired with a strong spoken answer. It invites a coherent explanation of the solution or implementation rather than testing an isolated saved detail; the learner's practice attempts are separate.
_Avoid_: Practice transcript, attempt history

**Spoken Reference Answer**:
A natural interview response that starts with plain language, keeps the technical terms needed for accuracy, and connects the solution to supported implementation evidence. It should be explainable aloud in roughly one to three minutes, not read like a textbook entry.
